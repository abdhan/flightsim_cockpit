# flightsim_cockpit
Mobiflight Project to make some flight controls using an Arduino Mega and basic electronic components.

## So far
| Component | Function | Pin1 | Pin2 | Pin3 |
| --------- | -------- | -------- | -------- | -------- |
| Rotary Encoder 1 | AP Altitude (INC/DEC + SLOW/FAST) and Push to ALT LOCK) | 
| Rotary Encoder 2 | !Heading! | | 45||
| Rotary Encoder 3 | !VS! | 47|46|44|
| Rotary Encoder 4 | !Elevator Trim! | 48|49|51|
| Rotary Encoder 5 |  | 50|53|52|
| LED 1 | AP Status | |||
| LED 2 | Landing Gear | |||
| LED 3 | Parking Break | |||
| LED 4 |  | |||
| LED 5 |  | |||
| Trim Pot || |||

Currently, its mounted on a cardboard box.
